# 阿斗溜溜球

一只被当成溜溜球甩的阿斗。背后的 K 线按 A 股习惯着色：红涨，绿跌。跌破 5%，阿斗会摔在地上，然后被拉起来继续甩。

## 微信里直接玩

打开这个网页即可，不用下载：

https://zbcc0826.github.io/adou-yoyo/

## 操作

画面下方有按钮，手机上直接点。

- **输送天意**（↑）：略微提高上涨概率。
- **加仓**（空格）：按现价再买 200 股，把成本往现价摊薄。
- **声音**：开关和音量在同一排。背景是很轻的雨声，旋律在宫商角徵羽上走，笛、箫、筝轮流，底下有持续的低音。摔倒、扔喇叭、输送天意、加仓也用这套开关和音量。公开仓库不附带别人的歌曲录音。

左上角会显示输送天意的次数，以及总盈亏的金额和百分比。
