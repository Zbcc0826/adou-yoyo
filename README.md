# 老实玩新三国梗很枯燥吧

一只被当成溜溜球甩的阿斗。背后的 K 线按 A 股习惯着色：红涨，绿跌。跌破 5%，阿斗会摔在地上，然后被拉起来继续甩。

打开这个网页即可，不用下载：

https://zbcc0826.github.io/adou-yoyo/

## 操作

画面下方有按钮，手机上直接点。

- **输送天意**（↑）：略微提高上涨概率，也略微提高下一根出三国事件的概率。
- **加仓**（空格）：按现价再买 200 股。现金可以买成负数。现金不为负时杠杆率是 0%；欠了钱以后，杠杆率才是持仓市值除以净资产。现金为负时，每 10 根 K 线按杠杆率扣一次利息。杠杆率到 200% 会强平。
- **卖出**（S）：按现价卖出 200 股。卖出会降低杠杆。
- **强平**：杠杆率到 200% 时这一把结束，结算里能看到注入天意的次数、盈亏比、最高盈利比、最高净资产、阿斗摔倒次数，以及这一把遇到的事件。点「下一把」重新开始，不保留上一把。
- **声音**：开关和音量在同一排。背景按春江花月夜、梅花三弄、阳关三叠、茉莉花的节奏和音程一路接下去，句和句之间不空拍。笛、箫、筝一起响，不轮换，音量很轻。摔倒、扔喇叭、输送天意、加仓、卖出、负现金加杠杆、强平也用这套开关和音量。

每根 K 线有很小的概率冒出一条三国事件。字幕像天意那样打出来，并改这一根或后面几根的形态。不按史序，同一条也可以再出现。曲子按这些名曲的音程和节奏自己接，不抽随机乐句，仓库里不附带别人的歌曲录音。

有没有更神的神人，再增加一些事件和插图。

行情牌上成本、持仓、现金的位置是固定的，成本和现金数字右对齐。总盈亏这一列上面是金额，下面是大号百分比，杠杆率同样占两行。现金不为负时杠杆率是 0%。输送天意和摔倒次数在底部按钮旁边。右上角的按键提示点一下，说明文字会收到右边，只留下快捷键。再点一下展开。
